# 失败处置手册（failure_playbook）

原则：同一处失败修两次仍失败，必须切换策略类别；任何时候禁止以删除断言、裸 except、填占位值的方式"让脚本跑完"。

| 症状 | 最可能原因 | 处置（按序） |
|---|---|---|
| `KeyError: '列名'` / 断言门报缺列 | 列名凭记忆拼写，与表头不符（空格、大小写、单位括号） | 回口径表，从表头逐字复制列名；建立 rename 映射，不在全脚本散落原始列名 |
| `UnicodeDecodeError` | 编码非 UTF-8（仪器导出常见 GBK/Latin-1） | 显式编码链：utf-8-sig → utf-8 → gb18030 → latin-1，把实际命中编码记入 provenance；禁止 errors='ignore'（会静默丢字符） |
| `pandas` 导入失败 | 环境无该依赖 | 回退纯标准库（csv/sqlite3/statistics），在 provenance 记录 pandas 不可用；禁止 pip install |
| `matplotlib` 导入失败 | 无绘图库/无显示后端 | `matplotlib.use('Agg')` 重试一次；仍失败则保存绘图数据 CSV，result.json 中声明图未渲染，绝不交付空 PNG |
| SQL 返回 0 行 | 表名/列名错误、连接键类型不符、WHERE 条件过严 | `.tables` 与 `PRAGMA table_info` 核对；逐步去掉 WHERE 条件定位是哪一条把行滤光；确认后仍为空才允许报告，并写明"空结果已核实" |
| SQL 行数远多于预期 | 漏了 WHERE/连接条件，或重复记录未处理 | 与 `SELECT COUNT(*)` 基线对比；检查 join 扇出；回口径表核对筛选条件 |
| 数值与复核块不一致 | 两种实现口径不同（缺失值处理、std 的 n vs n-1、百分位插值） | 先怀疑计算段：打印两侧中间量对比；确认口径后统一；不许通过放大容差放行 |
| `MemoryError` / 超时 | 一次性载入过大 | CSV 改逐行流式聚合；聚合下推到 SQL；只读必需列 |
| 浮点诡异（如 0.1+0.2） | 二进制浮点 | 比较用相对容差 1e-6；展示位数按数据字典有效数字四舍五入，原始值不截断存入 result.json |
| 统计检验前提不满足 | 分布明显偏态/样本量过小 | 在结果中声明前提未满足及影响，换稳健方法或只做描述统计；不许照常报 p 值当无事发生 |
| 时间不够跑完全部任务 | 预算耗尽 | 保留已验证部分，status=partial，anomalies 列未完成项与原因；优于交付未验证的"完整"结果 |
